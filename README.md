# 电火花加工工艺参数优化

基于脉冲放电特征数据，识别工作液流量（DFlow）与放电间隙（DGap）的量化关系，构建「特征识别 — 链式协同 — 双模型预测」的一体化数据驱动框架，为电火花加工（EDM）在线参数的智能推荐提供模型与理论依据。

## 问题背景

电火花加工利用电极与工件之间的脉冲放电蚀除材料，不受材料硬度限制，广泛用于模具制造与精密加工。加工过程中，**工作液流量 DFlow** 与 **放电间隙 DGap** 是影响排屑、冷却、放电稳定性及加工精度的两个关键控制变量（取值均为 {-1, 0, +1}）。二者调节不当易导致短路、断弧、粗糙度恶化，因此需要从脉冲特征中识别合理的控制策略。

## 数据

- 154 组样本，16 个脉冲特征（含 CSM/BSM 系列统计量等）
- 两个离散控制变量：DFlow、DGap
- 数据文件：`202601B题数据.xlsx`

## 方法与结果

**问题一 · 量化关系识别**：Pearson 相关分析 + 随机森林重要性评估，识别出 CSM\_C\_MeanT、BSM\_B\_MeanT 等关键特征，揭示 B 类与 C 类脉冲时间特征在间隙变化下「此消彼长」的演变规律；层次聚类 + PCA（前三主成分累计解释方差 78.07%）探明低维可分结构，并论证全特征建模的合理性。

**问题二 · 协同调控**：针对 DFlow 与 DGap 的「互斥偏移」结构性约束，引入分类器链（Classifier Chains）刻画联合控制概率；「先宏观基准、后微观精调」的 DFlow → DGap 链顺序最优，联合动作 Macro-F1 达 **70.3%**。

**问题三 · 最优参数预测**：「同框架、分任务」双模型策略——DFlow 用随机森林（Macro-F1 **89.0%**），DGap 用 RBF 核支持向量机（Macro-F1 **70.5%**），在 Pipeline 分层 5 折交叉验证下消除标准化信息泄露。

**控制律**：以信息熵量化预测置信度，设计双级递阶在线控制律，支持防抖参数推荐与闭环控制。
